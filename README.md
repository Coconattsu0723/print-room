# はじめての印刷室

[公開サイトを見る](https://coconattsu0723.github.io/print-room/)

初めてショップカードを印刷会社に入稿する人向けのガイドサイトです。サイズや用紙の選び方から、印刷データの作り方、入稿直前の確認までを6本の記事にまとめました。

## 主な機能

- **ガイド一覧** — キーワード検索と工程別の絞り込みを組み合わせられます。検索条件はURLに反映されます。
- **入稿前チェック** — 6項目の確認状況をブラウザに保存し、進捗を表示します。チェックは一括で解除できます。
- **記事とチェック項目の行き来** — チェック画面から解説を読んだあと、対応する項目に戻れます。

## 制作

自主制作として、企画、情報設計、記事執筆、デザイン、実装、動作確認、公開まで担当しました。

PencilでスマートフォンとPCの画面を設計し、HTML・CSS・JavaScriptで実装しました。公開にはGitHub Pagesを使用しています。
